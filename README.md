# Hava Məlumatı

Bu layihə istifadəçinin seçdiyi şəhərin cari hava vəziyyətini və 7 günlük hava proqnozunu göstərən sadə veb tətbiqidir.

## Layihə haqqında

İstifadəçi şəhərin adını daxil edərək həmin şəhər haqqında hava məlumatlarını əldə edə bilər. Layihə hava məlumatlarını Open-Meteo API vasitəsilə alır.

## Əsas xüsusiyyətlər

- Şəhər üzrə hava axtarışı
- Cari temperaturun göstərilməsi
- Hiss olunan temperatur
- Rütubət məlumatı
- Külək sürəti
- Cari yağıntı məlumatı
- Hava vəziyyətinin göstərilməsi
- 7 günlük hava proqnozu
- Günlük yağış ehtimalı
- Günlük maksimum külək sürəti
- Azərbaycan şəhərləri üçün axtarış təklifləri
- Mobil cihazlar üçün uyğun responsive dizayn

## İstifadə olunan texnologiyalar

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## API

Layihədə hava məlumatlarını əldə etmək üçün Open-Meteo API istifadə olunur.

## İstifadə

1. Şəhərin adını axtarış bölməsinə daxil edin.
2. "Axtar" düyməsinə klikləyin.
3. Cari hava məlumatlarına və 7 günlük proqnoza baxın.

Layihənin işləməsi üçün internet bağlantısı tələb olunur.
